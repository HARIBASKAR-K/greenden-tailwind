# 🌿 Greenden – Responsive Website (Tailwind CSS)

Greenden is a responsive multi-page website built using HTML and Tailwind CSS.  
This project demonstrates my ability to design modern, clean, and mobile-friendly user interfaces using Tailwind’s utility-first approach.

---

## 📌 Project Overview

Greenden introduces users to real-world website layouts while focusing on responsive design, accessibility, and clean UI structure.

---

## 🖥 Live Website
https://haribaskar-k.github.io/greenden-tailwind/

## 🚀 Pages Included

- Home Page – Eye-catching hero layout with introduction  
- Products Page – Grid-based product card layout  
- Contact Page – Styled contact section and information  

---

## ✨ Features

- Modern UI built with Tailwind CSS  
- Fully responsive design for all screen sizes  
- Flexbox & Grid based layouts  
- Utility-first clean class structure  
- Mobile-first development approach  
- Professional spacing, typography & alignment
